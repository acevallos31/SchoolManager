# UX referencia vertic — Objetivo 3 bloqueado

Estado: BLOQUEADO. No implementado.

## Motivo

El objetivo 3 de la sesión 019-ux pedía comparar la UX de alumnos con
`vertic-platform` / `vertic-demo` **solo como referencia visual**. Ambos
repos no están presentes localmente (`/opt/projects/vertic-platform` y
`/opt/projects/vertic-demo` no existen) ni se aportó una URL accesible.

## Decisión

Siguiendo la instrucción del usuario, **no se espera por vertic-demo**: el
objetivo queda documentado como bloqueado por ausencia de repos/URL y la
sesión continúa con evidencia local (ver `019-workspace-contextual-alumno-diseno.md`).

## Pendiente

Para retomar el objetivo 3 hace falta que se provea al menos uno de:
- los repos clonados en `/opt/projects/` (p. ej. `vertic-demo`), o
- una URL pública de la app/demo de referencia.

Mientras tanto el diseño se apoya en los patrones locales ya presentes en el
repo (matriculas/responsables) para consistencia.
