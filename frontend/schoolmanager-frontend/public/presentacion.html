SchoolManager

Una plataforma web para organizar la operación académica de una institución: alumnos, responsables, ciclos, períodos, matrículas y configuración financiera, con reglas consistentes y trazabilidad desde la interfaz hasta PostgreSQL.

Angular standaloneASP.NET Core .NET 10PostgreSQL + RLS/RPCVercel + Render

1. Problema

Muchas instituciones comienzan con hojas de cálculo, mensajes y procesos separados. Esa fragmentación provoca duplicados, matrículas sin contexto, permisos difíciles de auditar y poca visibilidad sobre el estado real de cada estudiante. SchoolManager nace para centralizar el ciclo académico sin convertir la operación en un sistema pesado: cada dato se relaciona con su institución, ciclo, período y responsable, y cada acción queda protegida por permisos.

2. Solución

El producto presenta un AppShell común y módulos enfocados. El usuario inicia sesión con Supabase Auth; la API .NET valida el JWT, resuelve la identidad y aplica permisos RBAC. Las escrituras sensibles viajan al backend y a funciones SQL protegidas, donde viven las invariantes de negocio. La base conserva históricos y usa RLS para el aislamiento institucional. Así, la interfaz es clara, pero la seguridad y consistencia no dependen de ella.

3. Funcionalidades

Alumnos

Alta, búsqueda, edición, documento e información de contacto, con autorización por permiso.

Matrículas

Relación alumno–ciclo–período–sección, estados controlados y rematrícula tras anulación conservando el historial.

Responsables

Vínculos responsables–alumnos y portal de consulta de información académica y financiera.

Configuración

Centro educativo, ciclos, períodos, grados, jornadas, secciones, conceptos y planes de pago.

4. Arquitectura

SchoolManager es un monolito modular: una sola aplicación desplegable, dividida por responsabilidades. Angular consume contratos HTTP de la API .NET; los controladores validan autorización y contexto institucional; PostgreSQL/Supabase ejecuta RLS, RPC y transacciones. Esta decisión evita complejidad prematura y mantiene el camino abierto para crecer cuando exista una necesidad real.

5. Tecnologías y calidad

El frontend utiliza Angular standalone y TypeScript estricto. El backend usa ASP.NET Core sobre .NET 10, con Npgsql para PostgreSQL. Supabase aporta autenticación y persistencia administrada. Vercel sirve la aplicación web y Render ejecuta la API en un contenedor Docker. El repositorio incluye migraciones SQL versionadas, rollbacks, validaciones y una matriz automatizada de pruebas.

  • 184 pruebas automatizadas en la línea base del bloque UX.
  • CI ejecuta build, pruebas API, pruebas DB, pruebas frontend, cobertura y Quality Gate.
  • SonarCloud analiza C# y TypeScript sin relajar umbrales.
  • Healthchecks separados: /health para vida y /health/ready para PostgreSQL.

6. Manual de uso

Para comenzar, abre la página de acceso y autentícate con una cuenta autorizada. Después del inicio de sesión, el AppShell muestra únicamente las opciones permitidas. En Alumnos puedes buscar o registrar personas; desde un alumno activo puedes iniciar una matrícula indicando ciclo, período, grado, jornada y sección. En Matrículas revisa estados y transiciones disponibles. En Configuración define primero el centro educativo y los catálogos académicos. Los mensajes de validación aparecen dentro del formulario y las acciones críticas solicitan confirmación.

Para una demostración segura utiliza datos de prueba. No se deben ejecutar pruebas destructivas ni introducir secretos en formularios públicos.

7. Cliente objetivo y valor

El cliente inicial es una institución educativa pequeña o mediana que necesita dejar atrás archivos dispersos sin adquirir un ERP sobredimensionado. Dirección obtiene una vista ordenada del ciclo escolar; administración reduce errores de captura; docentes y responsables consultan información según su permiso. La arquitectura multiinstitución y el historial de estados permiten comenzar con una escuela y crecer con control. El valor no es solo digitalizar pantallas: es volver verificable quién hizo cada operación y bajo qué contexto.
