SchoolManager es una plataforma web pensada para centralizar la información académica, administrativa y financiera de una institución educativa en un solo lugar.

Conocer la propuesta ↓
01 · El problema

La información no debería estar repartida.

En muchas instituciones, los datos de estudiantes, grados, matrículas, cargos y pagos se manejan en hojas de cálculo, documentos separados o sistemas que no comparten la misma información. Esto provoca duplicidad, errores al actualizar registros, pérdida de tiempo y poca visibilidad para tomar decisiones.

🧩

Datos fragmentados

La institución debe buscar la información en varias fuentes antes de completar una tarea sencilla.

⏱️

Procesos lentos

Registrar una matrícula o confirmar un pago puede requerir pasos manuales y repetitivos.

🔒

Control limitado

Sin roles y permisos claros, cada usuario puede terminar viendo más información de la necesaria.

02 · La solución

Un centro de control para la gestión escolar.

SchoolManager organiza el trabajo alrededor de la institución y sus procesos. La propuesta combina una interfaz sencilla con reglas de negocio, permisos y una base de datos preparada para crecer. El objetivo no es complicar la operación, sino hacer que cada persona encuentre rápido lo que necesita.

“Menos tiempo buscando datos. Más tiempo acompañando el aprendizaje.”
Centralizar
Unificar registros académicos.
Validar
Evitar datos incompletos.
Consultar
Encontrar información útil.
Decidir
Observar el estado real.
03 · Funcionalidades

Lo esencial, conectado.

Académico

Alumnos y personas

Gestiona perfiles, datos de contacto, código interno e identificación con una visión ordenada de cada estudiante.

Operación

Matrículas

Relaciona al alumno con su institución, grado, jornada y período, manteniendo reglas para evitar relaciones inválidas.

Finanzas

Cargos y pagos

Permite consultar obligaciones, registrar pagos y distinguir estados como pendiente, parcial, pagado o anulado.

Seguridad

Roles y permisos

La navegación y las operaciones se protegen con guards, permisos explícitos y validaciones también en el backend.

Calidad

Pruebas automatizadas

La base de datos, la API y el frontend cuentan con pruebas que ayudan a detectar regresiones antes de publicar.

Experiencia

Interfaz responsive

El AppShell y los componentes visuales permiten una experiencia consistente en computadora y dispositivos móviles.

04 · Arquitectura

Capas con responsabilidades claras.

La solución separa la presentación, la API y la persistencia. Esta decisión facilita el mantenimiento: una mejora visual no obliga a reescribir la base de datos, y una regla de negocio puede probarse sin depender de toda la pantalla.

Usuario
navegador / móvil
→
Angular
interfaz y guards
→
API .NET
reglas y autorización
→
PostgreSQL
datos, RLS y RPC

La arquitectura también contempla health checks de liveness/readiness, análisis de calidad con SonarCloud y pipelines de integración continua.

05 · Tecnologías

Construido para aprender y evolucionar.

Frontend

Angular + TypeScript para construir una aplicación modular, con componentes reutilizables, rutas protegidas, formularios y diseño responsive.

Backend y datos

ASP.NET Core + PostgreSQL para exponer una API estructurada, aplicar reglas de negocio y guardar la información con relaciones y restricciones.

Calidad

GitHub Actions, NUnit, pruebas de API y SonarCloud para revisar automáticamente compilación, pruebas, cobertura y problemas de código.

Despliegue

El frontend se publica como aplicación web y el backend cuenta con endpoints de salud para facilitar la observabilidad del servicio.

06 · Manual de uso

Un flujo sencillo para el usuario.

Ingresar. Accede con tus credenciales. El sistema identifica la sesión y carga los permisos correspondientes.

Revisar el panel. Desde el Dashboard puedes observar indicadores y entrar a los módulos disponibles.

Buscar un alumno. Usa el módulo de alumnos para localizar un registro y consultar su información principal.

Gestionar el proceso. Según tu rol, crea o actualiza una matrícula, un cargo o un pago. El sistema valida los datos antes de guardar.

Confirmar. Revisa el mensaje de resultado y vuelve al listado para verificar que la información quedó actualizada.

07 · Cliente y contexto

Una solución pensada para una institución real.

El producto se plantea para una institución educativa que necesita administrar su operación diaria sin depender de archivos dispersos. SchoolManager puede crecer desde una institución inicial hacia un escenario multiinstitución, manteniendo separados los datos y las reglas de cada organización. Esto permite que el proyecto académico tenga una dirección práctica: resolver un problema reconocible y demostrar decisiones de ingeniería.

Cliente objetivo

Dirección, administración, docentes y responsables financieros de centros educativos.

Beneficio principal

Una vista confiable de alumnos, procesos académicos y obligaciones económicas.

Escalabilidad

El modelo está preparado para agregar módulos sin perder orden ni control de acceso.
